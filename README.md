# Practical Hoops

A browser-based original basketball prototype inspired by modern practical basketball gameplay.

## Play
Open `index.html` in a browser. The project uses Three.js from a public CDN.

## Current prototype
- 3D court, hoops, player, defender and ball
- Third-person camera with mouse drag
- WASD movement + sprint/stamina
- Timed green shooting meter
- Dunk trigger near the rim
- Crossover, behind-back, spin, stepback and post-move inputs
- Tab HUD
- Mobile touch controls
- 1v1 practice shell
- Build Creator / Jumpshot Creator / Park menu placeholders

## Controls
WASD move, Shift sprint, E shoot/release, Space dunk, Z/X/C/V/G moves, Tab HUD, drag mouse camera.

This is an original prototype and does not copy Practical Basketball's proprietary code, assets, animations, branding or UI.
